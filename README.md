# Developer Resources

Welcome to the BitDance developer resource hub. Here you will find all the essential API specifications, wallet integration guides, and tools to help you build and integrate with BitPocket Wallet and related services (such as bitboom).

## 📖 Read the Documentation

All developer documentation is published and maintained on the BitDance open platform. Please visit the link below to access the complete and up-to-date guides:

### 🌐 [BitDance Open Platform Documentation](https://docs.bitdance.network/)

The documentation site covers:

- **BitDance Open API** — Apply for an ApiKey and access the Open API reference.
- **BitPocket Wallet API** — Wallet integration guides for BTC and Lightning Network.
- **xL402 Gateway** — Lightning-native HTTP micropayment gateway (x402-V2) for per-request billing on any HTTP API.

> The content in this repository is synced from the documentation site. For the latest version, always refer to [docs.bitdance.network](https://docs.bitdance.network/).
